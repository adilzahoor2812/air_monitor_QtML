# Fonts — industrial HMI practice

**Roboto** (Apache 2.0) is used here — a common choice for operator panels,
Android industrial HMIs, and dense numeric UIs (clear glyphs, good digit
legibility).

| File | Use |
|------|-----|
| `roboto_regular_12` | Labels, captions |
| `roboto_regular_14` | Titles |
| `roboto_medium_16` | Units (°C, %) |
| `roboto_medium_20` | Zone status |
| `roboto_medium_28` | Sensor values |

Sources: Google Fonts Roboto. Regenerated with `lv_font_conv` (bpp 4).
